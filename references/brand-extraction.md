# 브랜드 토큰 자동 추출

새 브랜드 톤으로 덱을 만들려면 그 브랜드의 규칙을 먼저 알아야 한다. 덱 전체를 받을 필요는 없다. **형태가 다른 대표 슬라이드 2~3장**이면 반복 요소를 찾을 수 있다.

## 사용자에게 요청하는 문구

Stage 0에서 그대로 쓴다.

> 브랜드 톤을 잡기 위해 **자주 쓰시는 슬라이드 2~3장**을 `.pptx` 파일로 주시겠어요?
> 아래처럼 **형태가 서로 다른 것**으로 골라주시면 정확합니다.
>
> 1. **표가 들어간 장** — 표 헤더 색과 행 높이를 봅니다
> 2. **좌우로 나뉘거나 목록이 있는 장** — 본문 영역과 여백을 봅니다
> 3. (있다면) **도식이나 숫자가 큰 장** — 강조 색과 도형 문법을 봅니다
>
> 표지나 간지만 있으면 본문 규칙을 못 찾으니 **본문 슬라이드를 꼭 포함**해 주세요.
> 파일은 원본 그대로 주시면 되고, 내용은 읽지 않고 서식만 봅니다.

내용이 민감하면 이렇게 덧붙인다.

> 숫자나 고유명사는 아무 값으로 바꾸셔도 됩니다. 서식만 유지되면 됩니다.

## 실행

```bash
python3 scripts/extract-brand.py 레퍼런스.pptx --name acme --out references/brands
```

`references/brands/acme/`에 두 파일이 생긴다.

| 파일 | 용도 |
| --- | --- |
| `brand.json` | 빌더와 프리뷰가 읽는 토큰 |
| `tokens.md` | 근거가 붙은 관찰 표. 사람이 검토한다 |

표준 라이브러리만 쓰므로 설치할 것이 없다. 원본은 읽기만 하고 수정하지 않는다.

## 뽑히는 것

| 항목 | 근거 |
| --- | --- |
| 캔버스 크기와 비율 | `presentation.xml`의 `sldSz` |
| 폰트와 자주 쓰인 크기 | 텍스트 run의 `typeface` / `sz` 빈도 |
| 팔레트 | 텍스트 색과 채우기 색을 나눠 빈도순으로 |
| 헤더 구분선 | 여러 장에서 **같은 좌표에 반복**되는 가로선 |
| 본문 영역 | 구분선의 x와 폭. 없으면 구조 블록(폭 2in 이상)의 바깥 경계 |
| 콘텐츠 하단 | 구조 블록 하단의 95퍼센타일 |
| 표 스타일 | 첫 행 채우기 색, 헤더 행 높이, 본문 행 높이 |
| 도형 문법 | `prstGeom` 빈도 |

## 판단 기준

**반복이 곧 규칙이다.** 여러 슬라이드에서 같은 좌표에 나타난 요소만 브랜드 규칙으로 본다. 한 장에만 있는 것은 그 장의 사정일 수 있다. 그래서 2장 이상을 받는다.

**경계는 중앙값이 아니라 바깥값이다.** 본문 영역을 중앙값으로 잡으면 작은 장식 도형에 끌려 안쪽으로 좁아진다. 폭 2in 이상 블록만 보고 바깥 경계를 쓴다.

**하단은 최대값이 아니라 95퍼센타일이다.** 한 장에서 흘러넘친 도형 하나에 전체 기준이 밀리지 않게 한다.

## 결과를 그대로 믿지 않는다

`needs_check`에 확인할 점이 나온다. 사용자에게 그대로 전달한다.

- 슬라이드가 1장이면 반복 검증을 못 했다는 경고
- 2장이면 3장 이상을 권하는 안내
- 헤더 구분선을 못 찾음 → 본문형 슬라이드가 있었는지
- 표가 없었음 → 표 스타일을 못 뽑음
- 폰트를 못 찾음 → 텍스트가 이미지로 들어간 슬라이드일 수 있음

`tokens.md`의 `not found`는 **그 슬라이드들에 없었다**는 뜻이지 브랜드에 없다는 뜻이 아니다. 단정하지 않는다.

## CP2에서 확인받는다

추출 결과는 그대로 쓰지 않고 `tokens.md`를 사용자에게 보여준 뒤 확정한다. 특히 아래는 자동 추출이 자주 틀린다.

- **강조색**: 빈도가 높다고 강조색은 아니다. 배경으로 넓게 깔린 색이 1위로 잡힐 수 있다.
- **본문 최소 크기**: 각주까지 섞여 최빈값이 실제 본문보다 작게 나올 수 있다.
- **금지 패턴**: 자동으로 알 수 없다. "이 레퍼런스에 없는 것"은 사람이 짚어야 한다.

## 검증

개발 시 실제 제안서 레퍼런스 32장 중 **본문 3장만** 넣어 수동 실측치와 대조한 결과다.

| 항목 | 3장 추출 | 32장 수동 실측 |
| --- | --- | --- |
| 캔버스 | 11.693 x 8.267 | 11.693 x 8.267 |
| 헤더 구분선 | x=0.649 y=1.343 w=10.37 | 동일 |
| 본문 영역 | 좌 0.649 / 폭 10.37 | 동일 |
| 콘텐츠 상단 | 1.553 | 1.55 |
| 콘텐츠 하단 | 7.71 | 7.58 |
| 표 헤더 채우기 | `#BAE8FB` | 동일 |

하단만 0.13in 차이가 났다. 표본이 적을수록 이 값이 헐거워진다.
